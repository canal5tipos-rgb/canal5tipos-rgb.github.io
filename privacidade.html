Política de Privacidade do Publicador

Atualizada em 23 de novembro de 2026.

O que o app acessa

Ao entrar com a conta do Google, o usuário autoriza o Publicador a:

  • enviar e agendar vídeos no próprio canal do YouTube (escopo youtube.upload);
  • ler dados do próprio canal e dos próprios vídeos, como título e visualizações (escopo youtube.readonly);
  • ler relatórios do YouTube Analytics do próprio canal, como retenção (escopo yt-analytics.readonly).

Onde os dados ficam

O app roda só no computador do usuário. Os tokens de acesso e os dados lidos do YouTube ficam guardados nesse computador. Não há servidor do Publicador recebendo esses dados.

Compartilhamento

Os dados não são vendidos, compartilhados nem enviados a terceiros. Eles são usados só para enviar e agendar os vídeos do usuário e para mostrar os números dos próprios canais a ele.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar o arquivo de tokens no computador também remove o acesso guardado.

Contato

Use o e-mail de suporte exibido na tela de permissão do Google ao entrar no app.
